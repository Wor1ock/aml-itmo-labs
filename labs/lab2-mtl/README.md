# ЛР2. Multi-task learning на PTB-XL

Один общий энкодер читает 12 отведений ЭКГ и решает три разные задачи: диагностику
(5 суперклассов, multi-label), класс ритма и регрессию возраста. Работа проверяет, когда
совместное обучение помогает, а когда мешает: single-task baseline, леave-one-task-out,
равные веса, uncertainty weighting и PCGrad.

Исходное ТЗ лежит в [`TASK.md`](TASK.md), общие требования курса — в
[`../README.md`](../README.md).

## Что внутри

| Задача | Роль | Метка | Тип | Метрики |
|---|---|---|---|---|
| диагностика | основная | 5 суперклассов SCP-ECG | multi-label | macro-AUC, macro-F1, per-class P/R/F1 |
| ритм | вспомогательная | класс ритма | multi-class | macro-F1, accuracy, confusion matrix |
| возраст | вспомогательная | лет | регрессия | MAE, RMSE, R² |

Метки берутся из `scp_codes` и разводятся по семействам через `scp_statements.csv`:
диагностические statement идут в первую голову, ритмические — во вторую. Колонка
`report` с текстом заключения, а также `site`, `nurse`, `device` в модель не подаются:
это короткие пути к диагнозу, а не признаки.

## Быстрый старт

```bash
./run.sh                     # docker compose build + полный прогон
```

или по шагам:

```bash
docker compose build         # в образе: зависимости, скачивание PTB-XL и предобработка
docker compose run --rm app  # EDA + сетка экспериментов + отчёт
docker compose run --rm smoke  # маленькая подвыборка, 1 эпоха, 1 фолд
docker compose run --rm test   # mypy + pytest
```

Результаты появятся в `outputs/`, отчёты — в `report/eda.html` и `report/index.html`.

Локально без Docker (нужен `uv`):

```bash
uv sync
uv run ecgmtl prepare              # скачать и подготовить данные (~2 ГБ загрузки)
uv run ecgmtl eda                  # report/eda.html
uv run ecgmtl experiments          # сетка условий x фолды
uv run ecgmtl report               # report/index.html
```

Версии фиксированы: Python 3.11, `torch==2.5.1+cu121` (индекс `download.pytorch.org/whl/cu121`,
работает на драйверах не ниже 525, включая 12.x), остальное — по `uv.lock`.

На машинах, где `physionet.org` недоступен, скачивание идёт с зеркала официального
архива 1.0.3 на Hugging Face: `--set data.prefer_mirror=true`. В Dockerfile этот
флаг включён по умолчанию, переключение — `--set data.prefer_mirror=false`.

## Данные

- PTB-XL 1.0.3, 21 799 записей, 18 885 пациентов, 12 отведений, 10 с.
- используется версия 100 Гц (`records100`), 500 Гц не скачивается;
- лицензия ODC-BY 1.0, цитирование: Wagner et al., *Scientific Data* 7, 2020;
- сырые данные в репозиторий не попадают: скачивание и предобработка идут на сборке
  образа, а распакованный архив после этого удаляется;
- предобработка: чтение WFDB → z-score по каждому отведению → memmap `float16`
  `(N, 12, 1000)` + манифест `parquet`.

## Split

`strat_fold` из PTB-XL стратифицирован по пациенту, поэтому пересечения пациентов между
частями нет по построению (это проверяется тестом и на каждом запуске).

| прогон | тест | валидация | train |
|---|---|---|---|
| 0 | 10 | 9 | 1–8 |
| 1 | 8 | 7 | остальные |
| 2 | 6 | 5 | остальные |
| 3 | 4 | 3 | остальные |
| 4 | 2 | 1 | остальные |

Пять прогонов дают пять разных тестовых выборок; тест не участвует в выборе эпох, весов
и стратегии. Early stopping и подбор `pos_weight` — только по валидации.

## Метод

- общий энкодер: три блока `Conv1d + BatchNorm + GELU + MaxPool` по 12 отведениям,
  attention pooling по времени, проекция в `h` размерности 256;
- головы: отдельные двухслойные MLP на `h`; головы не делят параметры между собой;
- лосс: `L = Σ w_i · L_i`, `L_diag` — BCE с `pos_weight` по train, `L_rhythm` —
  cross-entropy, `L_age` — SmoothL1;
- маски: запись без rhythm statement или без возраста не даёт градиента в эту голову;
- стратегии: равные веса, uncertainty weighting (`L_i / (2σ_i²) + log σ_i`), PCGrad
  на градиентах общего энкодера;
- конфликт градиентов считается как косинус между градиентами задач на энкодере.

## Сетка экспериментов

| условие | задачи | веса |
|---|---|---|
| `single_diag`, `single_rhythm`, `single_age` | одна | — |
| `mtl_equal` | три | равные |
| `mtl_uncertainty` | три | обучаемые |
| `mtl_pcgrad` | три | равные + проекция |
| `loto_no_rhythm`, `loto_no_age` | две | равные |
| `mtl_age_weight_0.1` | три | ручной sweep |

Основная таблица — 5 фолдов, абляции — 2 фолда (это указано в отчёте).

## Результаты

Заполняется после прогона: таблица «задача × метод» с mean ± std и 95% CI, дельты
против single-task, кривые обучения, конфликт градиентов, примеры расхождений.

## Ограничения

- одна модальность: модель видит только сигнал ЭКГ;
- классы ритма отобраны по частоте, редкие ритмы и их записи не используются;
- суперклассы разрежены (`HYP` встречается примерно в 12% записей), macro-AUC по ним
  шумит;
- абляции идут на двух фолдах;
- разброс между фолдами больше, чем разница между некоторыми стратегиями.
